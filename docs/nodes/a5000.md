## Rules that are easy to forget on a new machine

These live in the A40 node's Claude Code memory, which does not travel:

- Reply to the user in Korean; code, commits and documents in English.
- `--predictor sim` runs touch no GPU; `--max-workers` means CPU cores.
  Never run a simulation while hardware is being measured on the same node.
- GPUs may be used without asking, but record their occupancy (`nvidia-smi`
  before and after) in every raw file, and never measure beside another tenant.
- `pkill -f X` / `kill $(pgrep -f X)` kills the calling shell whenever `X`
  appears anywhere in the same command: issue kills as their own command.
- heteropilot's `compile.sh` aborts on its own bare `pip3`, and heteropilot's
  `.gitignore` does not cover `.venv`: see `REPRODUCE.md` (the
  `info/exclude` lines) and `docs/nodes/PREP.md` step B.

## R4.2 — the profile (run on this node, in heteropilot, not here)

The profile is heteropilot data, so it is a heteropilot PR followed by a
submodule bump here. **Never edit `vendor/heteropilot`**: profile in a
separate heteropilot clone.

The existing A5000 bundle (`profiler/perf/A5000/meta-llama/Llama-3.1-8B/bf16`)
was made with vLLM 0.19.0, `tp_degrees: [1]`, `max_num_batched_tokens 2048`,
`max_num_seqs 256`, `attention_max_kv 16384`, factors 2.0, 3 measurement
iterations. Match every one of those; change only the TP list. The profiler
resumes by default -- an existing CSV keeps its rows -- so **do not pass
`FORCE`**: tp=1 must stay byte-identical (the E-G6 mock and every earlier
result read it), and the checksums below prove it did.

Record, in the table at the end of this file, before the run: node name,
GPU model and count, every GPU's UUID (`nvidia-smi -L`), driver
(`nvidia-smi --query-gpu=driver_version --format=csv`), CUDA, the process
binding used, `uptime` load, and `nvidia-smi` occupancy (must be empty).

## Commands

```bash
# 0. This repository, with its submodule and both venvs (docs/nodes/PREP.md B)
git clone --recurse-submodules https://github.com/swsok/heteropilot-graphsearch.git
cd heteropilot-graphsearch
uv venv --python 3.10 .venv && uv pip install --python .venv/bin/python -r requirements.txt
printf '.venv/\n.venv-vllm/\n' >> .git/modules/vendor/heteropilot/info/exclude
# simulator venv inside the submodule: PREP.md step B, both post-compile.sh lines

# 1. A separate heteropilot clone for the profile, on its own branch
cd ~ && git clone https://github.com/swsok/heteropilot.git heteropilot-a5000
cd heteropilot-a5000 && git checkout -b profile/a5000-tp2-tp4
uv venv --python 3.12 .venv-vllm
VLLM_USE_PRECOMPILED=1 uv pip install --python .venv-vllm/bin/python vllm==0.19.0 datasets matplotlib
source .venv-vllm/bin/activate          # profile.sh calls python3
export HF_TOKEN=...                     # Llama-3.1-8B is gated

# 2. Record the node, and fingerprint tp=1 before
nvidia-smi -L; nvidia-smi; uptime
find profiler/perf/A5000/meta-llama/Llama-3.1-8B/bf16/tp1 -type f | sort | xargs md5sum > /tmp/tp1.before

# 3. Edit profiler/profile.sh: MODEL="meta-llama/Llama-3.1-8B", HARDWARE="A5000",
#    TP_DEGREES="1,2,4" (or "1,2" with fewer than four GPUs); leave the other
#    values as they are (they match the bundle above); FORCE unset. Then:
./profiler/profile.sh 2>&1 | tee /tmp/a5000-profile.log

# 4. tp=1 must be unchanged; the new degrees must exist
find profiler/perf/A5000/meta-llama/Llama-3.1-8B/bf16/tp1 -type f | sort | xargs md5sum | diff /tmp/tp1.before - && echo TP1_UNCHANGED
ls profiler/perf/A5000/meta-llama/Llama-3.1-8B/bf16/   # tp1 tp2 (tp4)

# 5. heteropilot PR: the profile + a deviation entry (D129 is the last of the
#    D120-D129 block; D128 is PR #135) -- not the edited profile.sh
git checkout profiler/profile.sh
git add profiler/perf/A5000 && git commit && git push -u origin profile/a5000-tp2-tp4

# 6. After it merges: the submodule bump here, ALONE in its own PR, with the
#    full suite and heteropilot's golden tests (revision rule 0.7)
cd ~/heteropilot-graphsearch && git checkout -b exp/r4-2-bump-a5000
git -C vendor/heteropilot fetch && git -C vendor/heteropilot checkout <merged sha>
git add vendor/heteropilot && git commit
export PYTHONPATH=$PWD:$PWD/vendor/heteropilot
.venv/bin/pytest -q && ruff check . && mypy graphsearch/
(cd vendor/heteropilot && .venv/bin/pytest -q)            # golden tests
git -C vendor/heteropilot status --porcelain              # must be empty

# 7. R4.1, after the bump (CPU only; ~1.5-2 h at 60 workers; no hardware run meanwhile)
vendor/heteropilot/.venv/bin/python experiments/scripts/e_g6_real_sim.py --max-workers 60

# 8. R4.3: E-G3 re-run, appended as a new section, never overwriting the table
bash experiments/scripts/e_g3_oracle_run.sh --only graph-toy-abcde
bash experiments/scripts/e_g3_oracle_run.sh --only graph-toy-shared-nic
```
